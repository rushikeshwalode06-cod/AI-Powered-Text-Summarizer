# KnowSphere-AI-AI-Powered-Knowledge-Base-Search
🤖 AI-Powered Text Summarizer uses a fine-tuned T5-Small Transformer model to automatically convert long text into concise, meaningful summaries. Built with NLP, Hugging Face Transformers, BillSum dataset, and ROUGE evaluation, the project demonstrates end-to-end text summarization with an interactive Streamlit interface.
